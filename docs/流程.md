# 流程.md —— 从 0 到 1：给一个 JD，生成「保结构」的定制 Word 简历

> **读者：使用本工具的 AI Agent（或人）**。本文档假设你什么都不知道，请从头按顺序执行。
> 目标：输入一段 JD（文字或截图）→ 输出**不改版式**的定制 Word 简历 + 改动说明。

---

## 第 1 步 · 认识这套东西怎么工作（30 秒）

- Word 简历里每个「可改段落」被包了一个**内容控件锚点**（带 `tag`，如 `resume:intent`、`resume:proj.a.b1`）。
- 定制 = **只改锚点里的文字** → 字体/编号/图片/文本框/页眉页脚**原样不动**（这就是「保结构」）。
- 分工：**Agent 负责「想」**（读 JD、筛项目、改写措辞，产出 `fills.json`）；**脚本负责「改」**（按字数预算裁剪、写 Word、自检、交付）。

工具命令一律是 `jd2word <子命令>`（等价 `python -m jd2word.cli <子命令>`）。

**每条命令前先设编码（防中文乱码）**：`export PYTHONIOENCODING=utf-8 PYTHONUTF8=1`

---

## 第 2 步 · 环境自检

```bash
jd2word --help
```
- 若报「找不到 Word AI 引擎」→ 按 README 安装第三方依赖 word-ai，并设 `WORDAI_DIR`。
- 若报 `No module named langgraph` → 用装了 langgraph 的 Python（见 README 依赖）。

---

## 第 3 步 ·（一次性）给简历埋锚点

> 只在第一次、或换简历后执行。

```bash
# 3.1 看清有哪些段（同时导出槽位配置草稿）
jd2word discover "用户的简历.docx" --emit-config slots.json
```

编辑 `slots.json`：
- **删掉**不需要改的段（教育背景、个人信息里的固定项等）；
- 给保留的段起 `tag`（机器用）与 `label`（人看），如：
  ```json
  {"slots": [
    {"paraId": "4FF5168F", "tag": "resume:intent",   "label": "求职意向", "can_drop": false, "budget": 20},
    {"paraId": "3B53621B", "tag": "resume:proj.a.b1", "label": "项目A·要点1", "can_drop": true}
  ]}
  ```
- `budget` 省略时自动 = 现有字数 × 1.15；求职意向这类长短不一的段建议手给 `budget`。
- 项目要点类段设 `"can_drop": true`（允许清空）。

```bash
# 3.2 埋锚点
jd2word anchor "用户的简历.docx" --slots slots.json --out-dir .wordai
```
成功输出：`OK: 带锚点模板 -> …resume_template.docx`、`OK: 槽位地图 -> …docx_slots.json（N 槽，锚点校验通过）`。

产出：
- `.wordai/resume_template.docx` —— **基准模板**，之后每次都基于它改；
- `.wordai/docx_slots.json` —— **槽位地图**。

---

## 第 4 步 · 看清槽位地图

`docx_slots.json` 每个槽的关键字段：
- `tag`：锚点名（`fills.json` 用它）；
- `label` / `section`：中文含义；
- `budget_chars`：**这格能放的最大字数**（超了会被截断/降级）；
- `current_text`：模板原文（改动前对照 + 校验用）；
- `can_drop`：`true` 的槽（一般是项目要点）**允许清空**。

> 大文件不要全文 `Read`，用 `Grep` 定位 + 局部读。

---

## 第 5 步 · 解析 JD

把 JD 转成结构化要点：**岗位名 / 公司 / 地点 / 年限 / 硬技能关键词 / 职责要点**。

- **JD 是文字**：直接读。
- **JD 是截图**：只走 OCR：
  ```bash
  jd2word ocr --img "<截图路径>" --out "<工作目录>/jd.txt"
  ```
  然后**只读那个 txt**。
  > ⛔ **硬规则：绝不 `Read` 截图原图**（图片会进上下文并随每轮重发，极耗 token）；也别靠眼睛猜——防造假。

---

## 第 6 步 · Agent 的核心工作：筛选 + 改写 → 写 `fills.json`

### 6.1 想清楚三件事
1. **项目排序**：对每个项目按与 JD 的**相关度**排序。Word 是**固定槽位**，段落/项目块**不能整体搬移**，所以「排序」落地为：
   - 顺序基本合理 → **不动顺序**，用**内容强弱**体现（最相关的强化，最不相关的精简，`can_drop` 的要点可清空）；
   - 顺序明显不合理 → 用**槽位文本互换**把项目换位。
2. **技术栈筛选**：为保留的项目挑出与 JD 相关的技术栈，按相关度重排（JD 强调的放前）。**只挑、不加。**
3. **逐槽核对预算**：每个要改的槽，新文字长度 ≤ `budget_chars`；放不下就写更短的 `alternates`。

### 6.2 写 `fills.json`（只写要改的槽；不写 = 不改）
```json
{
  "jd_id": "ai-intern",
  "slots": {
    "resume:intent":    { "text": "求职意向：AI 开发实习生" },
    "resume:skill.pro": { "text": "专业技能：…", "alternates": ["更短的备选…"] },
    "resume:proj.a.b2": { "text": "" }
  }
}
```
规则：
- `text` 必须是该槽**填好后的完整文字**（含原前缀，如 `求职意向：`、`▸ `）；
- `alternates`：放不下时的依次备选；工作流选第一个 ≤ 预算的，都不行才按标点截断 `text`；
- `""` 空串：清空该槽（仅 `can_drop=true`）；
- 只做**重排 / 精简 / 措辞改写**，**不新增母版没有的技术/经历、不编数字**。

---

## 第 7 步 · 落地（脚本把 fills 变成 Word）

```bash
jd2word tailor --slots .wordai/docx_slots.json --fills fills.json \
  --jd-id ai-intern --out out/ai-intern
```
**成功标志**：末尾 **`结构校验: OK`**。
- 输出 docx：`out/ai-intern/ai-intern.docx`
- 若 `结构校验: FAILED`：**不要声称成功**，照问题行排查（多为预算/占位问题）。

---

## 第 8 步 · 交付前三查

```bash
jd2word verify out/ai-intern/ai-intern.docx \
  --slots .wordai/docx_slots.json --fills fills.json
```
✅ 默认三行即过：
- ① 结构计数全等；
- ② 未改动槽 == 模板原文（等价 diff 仅目标槽）；
- ③ 目标槽回读 == fills（**没被截断**）。

加 `--verbose` 逐槽打印明细。

---

## 第 9 步 ·（可选）打包交付

```bash
jd2word package out/ai-intern/ai-intern.docx out/ai-intern 交付-ai-intern \
  --slots .wordai/docx_slots.json
```
产出 `交付-ai-intern/`（含 `ai-intern.docx` + `changelog.md`）。若把 `匹配分析.md` 放进 `out/ai-intern/`，也会一起带上。

---

## 规则（违反即失败）

**A. 结构冻结（不破版）**：只改锚点文字；每槽 ≤ `budget_chars`；部件/段落/表格/图片/域/控件**计数必须零变化**。

**B. 伦理红线（不造假）**：不新增母版没有的技术/项目/经历；不编数字；不改时间段/职级/公司名；只重排/精简/改写，每处改动可核对。

**C. 隐私**：全程本地，不联网，不上传任何简历/JD/文档。

---

## 故障排查

| 现象 | 原因 | 处理 |
|---|---|---|
| 找不到 Word AI 引擎 | `WORDAI_DIR` 不对 / 未装 | 设 `WORDAI_DIR`，或按 README 安装 word-ai |
| `No module named langgraph` | 用错 Python | 用装了 langgraph 的解释器（见 README） |
| 输出文字以「，」/半词结尾 | **超出预算被截断** | 该槽写短点，或加 `alternates` |
| `anchor` 报锚点缺失 | 模板 paraId 变了 | 重跑 `discover` 更新 `slots.json` |
| `PermissionError [WinError 32]` | 目标 docx 正被 Word 打开 | 先关 Word |
| 控制台中文乱码 | 未设编码 | 命令前 `export PYTHONIOENCODING=utf-8 PYTHONUTF8=1` |
